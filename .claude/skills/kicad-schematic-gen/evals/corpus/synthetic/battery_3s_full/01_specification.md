## 1. Purpose & Function

A self-contained power module for a portable motion system. Takes USB-C Power Delivery input (15V profile), charges a 3S LiPo pack to a longevity-optimized 12.2V (4.07V/cell), and supplies two output rails: a wide-voltage stepper rail for a DRV8825 driver (single NEMA 17, 1.5A) and a regulated 5V logic rail for an ESP32 and peripherals. The board acts as the *sole* power source for the downstream control board. When USB-PD is plugged in, both outputs must be live regardless of battery state (dead, missing, or under-voltage-locked). When unplugged, both outputs run off the battery until the under-voltage cutoff trips.

## 3. Power Rails Required

| Rail        | Voltage          | Max Current | Source                              | Loads                                 |
|-------------|------------------|-------------|-------------------------------------|---------------------------------------|
| VBUS_USB    | 15V (when plugged) | 3A        | USB-C PD sink                       | Charger input, SYS rail (passthrough) |
| VBAT (pack) | 9.0 – 12.2V      | 3A         | 3S LiPo pack                        | Charger output, SYS rail (when unplugged) |
| VSTEPPER (SYS) | 9.0 – 15V (varies) | 2A peak | Charger SYS pin (max of USB / VBAT) | DRV8825 stepper driver, 5V buck input |
| +5V         | 5.0V regulated   | 1.5A       | Buck regulator from VSTEPPER        | ESP32 + peripherals (downstream)      |

**Note on VSTEPPER:** This rail is intentionally unregulated. It will sit at ~15V when USB-PD is plugged in and slide down with battery voltage when running on battery. The DRV8825 accepts VMOT from 8.2V to 45V, so this range is well within spec. No buck-boost needed.

## 4. Functional Blocks

### Block: USB-C PD Sink Controller
- **IC / approach:** Dedicated PD sink controller (candidates: CH224K, HUSB238, IP2721) — Stage 2 will compare
- **Interface:** Passive — configured via strap resistors or a fixed-profile pin to request 15V
- **Key signals:** CC1, CC2, VBUS, GND, VSEL/CFG pins
- **Notes:** Must request only 15V. If source can't supply 15V, board should fall back gracefully (no false-advertise 5V → battery, which would over-discharge). PD sink controllers handle this natively by not enabling VBUS until contract is met.

### Block: 3S LiPo Charger with System Power Path
- **IC / approach:** Multi-cell synchronous buck charger with **integrated system power path** (candidates: BQ25703A, BQ24650, MP2731) — Stage 2
- **Interface:** Hardware-configured (resistor-set charge current + voltage) preferred over I2C, to avoid host dependency. I2C version acceptable if hardware-only options don't fit.
- **Key signals:** VBUS in, BAT pin, SYS pin, sense resistor, status outputs (CHG, PG), thermistor
- **Critical requirement:** SYS pin must be live whenever VBUS is present, even if BAT is open-circuit or below UVLO. This rules out simple chargers like TP4056.
- **Notes:**
  - Pack: **3000 mAh** (user confirmed)
  - Charge target: **12.2V** (4.07V/cell, longevity profile) — set via feedback divider or programmed register
  - Charge current: **1.5A** (0.5C of 3000 mAh) — configurable via sense resistor
  - Pre-charge / termination / safety timer as supported by IC
  - Battery thermistor (NTC 10k) — on-board NTC near battery connector, wired to charger TS input. Monitors pack temperature during charge and pauses charging if outside 0–45°C.

### Block: Reverse-Polarity Protection (Battery Input)
- **Approach:** P-FET ideal-diode topology on the battery main input (B+ → charger BAT pin). If the JST-PH connector is plugged in reversed, the P-FET stays off and no current flows. Drop in normal operation is a few tens of mV.
- **Notes:** A Schottky in series would also work but wastes ~0.3–0.4V continuously. The P-FET version is the right call for a 3A path. Stage 2 will pick a specific FET (e.g., AO3401A, SI2301).

### Block: Battery Protection (Discharge-Side)
- **IC / approach:** Either (a) a dedicated 3S protection IC with external FETs (e.g., BQ77216 + dual N-FET), or (b) protection integrated into the charger if it supports discharge-side OCP/UVLO on its SYS path. Stage 2 will resolve.
- **Functions required:**
  - **Over-current protection (OCP):** Trip above 3A continuous on the discharge path
  - **Under-voltage lockout (UVLO):** Cut off load when pack drops below 9.0V (3.0V/cell) to protect cells from over-discharge
  - **Over-voltage protection (OVP):** Redundant per-cell OVP at 4.25V/cell as a backup to charger control
  - **Short-circuit protection (SCP):** Hard cutoff on dead short
- **Notes:** If the chosen charger handles SYS-side OCP/UVLO, we can avoid a second protection IC. Otherwise we add one. **Per-cell** monitoring (needed for OVP/UVLO per cell rather than pack-total) is preferred for safety.

### Block: Cell Balance — handled by pack BMS (no on-board connector)
- **Approach:** Cell balancing is handled entirely by the pack BMS (see R12). **No on-board balance connector.**
- **Rationale (revised 2026-06-01):** An earlier revision exposed a JST-XH 4-pin balance tap (J3) with per-tap ESD (D4/D5/D6). It was **removed** as functionally inert — the B1/B2 cell-midpoint taps had no on-board destination (they dead-ended at ESD diodes; nothing on the board monitors or balances cells), and B+/B− simply duplicated the main pack connector J2.
- **Notes:** If a cell ever drifts beyond what the BMS recovers, external balance charging is done by plugging the **pack's own balance lead** directly into a hobby balance charger — it does not need a board connector.

### Block: 5V Logic Buck Regulator
- **IC / approach:** Wide-input synchronous buck (candidates: MP2451, TPS54202, AOZ1280, RT8059) — Stage 2
- **Input range:** 9V – 15V (matches VSTEPPER)
- **Output:** 5.0V @ up to 1.5A
- **Notes:** SOT-23-6 or SOIC-8 with integrated FETs preferred over external-FET controllers. Add a power-good (PG) LED on the 5V rail.

### Block: Status Indicators
- **Power LED:** Green, on whenever VSTEPPER is live (≥6V). Confirms board has power.
- **Charging LED:** Red/amber, on while CHG status pin is active. Off when charge terminates.
- **PD-good LED:** Optional — confirms 15V contract negotiated. Defer to Stage 2; may be redundant with power LED.

## 6. Environmental & Mechanical

- **Operating temp:** Indoor ambient, 0–40°C (LiPo charging restricted to 0–45°C — charger IC NTC monitors pack temperature and pauses charging outside this window)
- **Board size & layout:** User handles during PCB layout. No size constraint at schematic stage.
- **Special:**
  - Thermal pad / copper pour required under the charger IC (it dissipates up to ~1.5W during full-current charge)
  - Switching node of the 5V buck should be small and tight
  - Battery main and stepper output traces sized for ≥3A (≥1.5mm width on 1oz copper)

## 7. Design Constraints & Preferences

- **Passive package:** 0805 (from preferences.yaml)
- **IC package preference:** SOT-23-5 → SOIC-8 → QFN/DFN (from preferences.yaml). For the charger and buck, the package will be dictated by what's available — these often only come in QFN.
- **Power style:** Power symbols (VBUS, +5V, GND etc.); net labels for everything else
- **Auto-decoupling:** Yes, one 100nF per IC plus bulk on each rail
- **Include power indicator LED:** Yes
- **PCB fab target:** JLCPCB (4-layer if needed for thermal/EMI on the charger; 2-layer if it fits cleanly)
- **Inventory parts to use:** AP2112K-3.3 is in stock but *not needed* on this board (the downstream ESP32 board handles its own 3.3V). Standard passives, LEDs from inventory.
- **Parts to be ordered:** Everything else — PD sink, charger IC, buck IC, power FETs (if protection circuit needs them), USB-C connector, JST-XH balance connector, sense resistors, inductor for buck, schottky if asynchronous topology.

## Requirements Checklist (the test suite later stages must satisfy)

- R1. Accept USB-C PD input, 15V/3A profile, negotiated by an on-board PD sink; no false 5V fallback.
- R2. **[CRITICAL]** SYS/VSTEPPER rail must be live whenever VBUS is present, even if the battery is absent, dead, or UVLO'd (integrated system power path).
- R3. Charge the 3S pack with a 12.2V (4.07V/cell) cutoff, set below the pack BMS OVP so the charger terminates.
- R4. Charge current ~1.5A (0.5C of 3000 mAh), resistor-set, no MCU dependency.
- R5. Temperature-qualified charging via an on-board NTC on the charger TS pin (pause outside 0–45°C).
- R6. Reverse-polarity protection on the battery main input.
- R7. USB-C input reverse-blocking so PD triggers reliably when plugged in on battery. The PD sink (CH224K) VBUS sense must see only the USB-connector VBUS, isolated from SYS/battery back-feed (it taps upstream of the VBUS→SYS ideal diode, which provides the reverse-block).
- R8. Provide an unregulated VSTEPPER rail (9–15V) to the DRV8825 stepper driver.
- R9. Provide a regulated +5V rail at up to 1.5A to the ESP32.
- R10. Expose CHG and PG charger status to the host.
- R11. **[CRITICAL]** Storage standby drain < ~100 µA (master switch off, **no USB present**) to protect shelf life. The master switch must de-energize **both** the +5V and VSTEPPER output rails (load-disconnect downstream of SYS/MUX). The switch itself is **external (user-supplied, mounted off-board)**; the board exposes a 2-pin SMD connector and does the high-current load-switching on-board, so only a µA control line runs out to the switch.
- R13. **Charge-while-off:** when USB-C is plugged in, the pack must charge **regardless of the master-switch position**, while the output rails (+5V, VSTEPPER) remain de-energized when the switch is off. Implemented by an input-present override (Q9 + R24/R25 divider) that forces the charger's DISQBAT low whenever VBUS is present; it does not affect the no-USB shelf standby of R11.
- R12. Cell balancing and pack protection (OVP/UVP/OCP/SCP) handled by the pack BMS — no on-board balance hardware.
